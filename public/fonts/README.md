# Fonts

Self-hosted copies of three Google Fonts families, Latin subset, variable where available.
All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which permits self-hosting and redistribution.

| File | Family | Source |
|---|---|---|
| inter-tight-latin.woff2 | Inter Tight 400–700 | https://fonts.google.com/specimen/Inter+Tight |
| instrument-serif-latin.woff2 | Instrument Serif Regular | https://fonts.google.com/specimen/Instrument+Serif |
| instrument-serif-italic-latin.woff2 | Instrument Serif Italic | https://fonts.google.com/specimen/Instrument+Serif |
| jetbrains-mono-latin.woff2 | JetBrains Mono 400–500 | https://fonts.google.com/specimen/JetBrains+Mono |

Fallback `size-adjust` values in `src/index.css` were measured by comparing rendered text widths
against Arial (Inter Tight, 94%) and Times New Roman (Instrument Serif italic, 89.5%).
